# VRC Italia Network design source

Files in this directory are the allow-listed source for **VRC Italia Network > Design Sync**.

- `site.css`: public visual design
- `site.js`: shared public UI behavior
- additional images may be placed below this directory

Do not place PHP, credentials, tokens or private data here. The synchronizer rejects PHP and unsupported extensions by design.

Changes become live only when a WordPress administrator manually runs **Synchronize design**.
